# Parking Lot Management System – C Day 112

## Description
A C application that manages vehicle parking records, assigns available slots and calculates parking charges during vehicle exit.

## Features
- Park a vehicle
- Automatically assign an available slot
- Prevent duplicate vehicle entries
- View all parked vehicles
- Search vehicles by number
- Calculate parking charges
- Remove vehicles after exit
- Save records permanently

## Technologies
- C Programming
- Structures
- Arrays
- File Handling

## Files
- `parking.c`
- `parking.txt`

## How to Compile
```bash
gcc parking.c -o parking
```

## How to Run
```bash
./parking
```

## Concepts Used
Structures, Arrays, Functions, String Comparison, Searching, Record Deletion and File Handling.

**Note:** This is an educational parking management simulation.
